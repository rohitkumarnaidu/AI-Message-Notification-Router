# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [2.0.0] - 2026-08-05
### Added
- Next.js enterprise dashboard with TailwindCSS and Framer Motion animations
- FastAPI REST backend with `/api/messages` and `/api/stats` endpoints
- Docker Compose multi-service orchestration
- Comprehensive TECHNICAL_DOCUMENTATION.md (860+ lines, 19 sections, 12 Mermaid diagrams)
- GitHub Pages documentation site

### Changed
- Upgraded README.md to reflect enterprise architecture
- Updated Dockerfile for FastAPI backend
- Updated docker-compose.yml for multi-container deployment

## [1.5.0] - 2026-08-04
### Added
- Phase 15 release candidate pipeline with confidence calibration
- Phase 14 structured router with 9 execution modes and automatic failover
- Phase 13 interruption policy (temporal context, relevance scoring, quiet hours)
- Phase 12 safety detection engine (7 detectors, 11 risk categories, multilingual)
- 118 deterministic tests with full CI/CD coverage
- Evidence retrieval with safety validation

## [1.0.0] - 2026-08-02
### Added
- Initial multimodal message notification router
- Gemini 2.5 Flash Vision integration for image OCR
- Groq Whisper ASR integration for voice transcription
- 27-rule deterministic baseline policy engine
- 40+ feature extractor with regex-based signal detection
- Dataset with 110 messages, 13 context CSV files
- Basic Streamlit dashboard (app.py)
